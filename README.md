# 📚 E-Library Platform

A modern full-stack digital library web application built using Django.

E-Library allows users to upload, manage, discover, read and download books through a clean and interactive interface.

---

## ✨ Features

### 👤 User System
- User registration
- Secure login/logout
- User-specific dashboard
- Profile dropdown

### 📚 Book Management
- Upload books with PDF files
- Edit uploaded books
- Delete books safely with confirmation
- View detailed book information
- Read PDFs directly in browser
- Download books

### 🔍 Discovery
- Explore all books
- Search books by title
- Search through descriptions
- Filter by category

### 🎨 User Interface
- Modern glass-style design
- Dark / Light mode
- Responsive layout
- Animated components
- Flash notifications
- Custom typography

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/atishaya2020-gif/E-Library-Django.git
```

Move into project

```bash
cd E-Library-Django
```

Create virtual environment

```bash
python -m venv .venv
```

Activate environment

Windows:

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Apply migrations

```bash
python manage.py migrate
```

Run server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
